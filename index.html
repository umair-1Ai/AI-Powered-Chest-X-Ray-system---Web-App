System Overview

AXDS (AI X-Ray Detection System) is an academic final year project using a deep learning model trained on chest X-ray images to classify pulmonary conditions. The model is based on EfficientNetB3, a convolutional neural network architecture optimized for accuracy and efficiency.

The backend is powered by FastAPI with a TensorFlow Lite interpreter. The frontend communicates via REST API for real-time predictions with server-side inference timing.

Detectable Conditions
COVID-19
Coronavirus infection causing bilateral ground-glass opacities in the lungs
Normal
No abnormalities detected in the lung fields
Lung Opacity
Increased density in lung tissue indicating fluid or consolidation
Viral Pneumonia
Lung infection caused by viral pathogens other than COVID-19
Known Limitations

No X-Ray Verification: The system does not verify whether the uploaded image is an actual chest X-ray. Non-X-ray images (photos, screenshots, documents) will still produce a prediction, which will be meaningless. Users must ensure they upload valid posteroanterior (PA) chest X-ray images only.

Lung Opacity Misclassification: Based on the confusion matrix, Lung Opacity has the highest misclassification rate (~11.86% confused with Normal), as the two conditions can appear visually similar in X-rays.

Platform Variance: Minor confidence score differences (~5–25%) may occur between the web and mobile apps due to platform-level image decoding and interpolation differences between Python PIL and Flutter's image library.
